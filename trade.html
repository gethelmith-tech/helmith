Lighter’s terms restrict access from some countries, including the United States, Canada and the United Kingdom, among others. Those terms belong to Lighter and can change. Do not use this interface to get around them. Read Lighter’s terms before you trade.

API key

Orders are signed in this browser with a Lighter API key generated on your device. The private key is stored only in this browser’s localStorage, encrypted with a signature from your wallet. Helmith has no server that could hold it. If you clear this site’s data, you will need to register a new key at the same index. Index 8 is reserved for this interface so a new key here will not replace keys used by Lighter’s own apps.
