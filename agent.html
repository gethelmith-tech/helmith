Helmith / Agent

Standing orders

How the helm will be held.

The agent is not at the wheel yet. These are the orders it will sail under once the desk is funded. They are written here first, so they cannot be softened after a loss.

What it is

Helmith is a single public desk, not a studio of paper bots. When it is under way, the agent will place perpetual orders on Lighter, on Robinhood Chain, using USDG as collateral. It will sign through an API key approved by the desk’s main account. That key will hold no funds of its own. The main key stays off the machine that sends orders.

Decisions will be written on the blotter with the fill that followed them. A reason without a fill is not a trade.

How it will decide

The first book will be narrow: a small number of liquid markets, at a modest size, under a hard leverage cap. The agent will not be asked to invent a new strategy mid-voyage. Entries, exits and a refusal to trade will all go in the log. If there is no edge worth the funding, the correct order is to stand off.

The limits that bind it

  • A maximum leverage well below Lighter’s market cap. The venue’s own maximum is not ours.
  • A maximum notional per order, and a cap on open risk across the book.
  • A daily loss limit. If it is reached, the agent stops for the rest of the day.
  • An API key with an expiry. When it lapses, the agent cannot send another order until the desk approves a new key.

These figures will be published on this page, in force, before the first real order. Until the desk is funded they are a standing policy, not a live setting on an account.

The kill switch

The desk can take the helm back at any time: cancel open orders, flatten positions, and revoke the agent key. A kill is a human order. The agent does not talk itself out of one.

If the key were stolen, it could still trade the desk’s margin until it is revoked or it expires. That is why the account will be a dedicated one, the key will lapse, and size will stay small. This is unlike a spot vault that cannot withdraw; a perp key can lose the margin in full.

No decision log will be staged here in advance. The first line in the book will be a real one.

Open the desk

Helmith is in development. The desk is not yet funded. A token has not been launched. Prices, funding and any future blotter rows are read from Lighter’s public API on Robinhood Chain.
