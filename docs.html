What Helmith is

Helmith is a public trading desk for perpetual markets on Lighter, on Robinhood Chain, with USDG as collateral. The site is a window onto that desk: live markets now, and a blotter that will show the desk’s own positions and fills once an account is funded.

It is in development. It is not a broker, not a place to deposit funds today, and not advice.

Where the figures come from

Prices, volume, open interest and funding are requested in this browser from Lighter’s public REST API, which allows cross-origin reads:

  • GET https://api.rh.lighter.xyz/api/v1/orderBookDetails
  • GET https://api.rh.lighter.xyz/api/v1/funding-rates — only rows whose exchange is lighter are shown as funding.
  • A funded blotter will also call /api/v1/account?by=index&value=… and /api/v1/trades?account_index=….

The ticker and the markets page refresh about every twenty seconds. If the API cannot be reached, the page will say so. It will not fill the table with remembered or invented numbers.

Open interest is shown as a USDG notional (size times mark). Volume is Lighter’s daily quote-token volume. Maximum leverage is computed from the venue’s minimum initial margin fraction, and is Lighter’s cap, not Helmith’s.

The blotter

The desk page reads HELMITH.account from js/config.js. Leave it null and the page shows an empty book. Set it to a Lighter account index, or to an L1 address, and the page will load that account’s collateral, positions and recent fills from the public API.

No row is drawn until that call returns one.

Limits and the kill switch

The standing orders for the agent — leverage, size, a daily loss halt, an expiring key, and a human kill switch — are described on the agent and risk pages. The numerical caps will be posted there before the first real order.

Token

A token has not been launched. No contract address is published. When one exists, it will appear on the token page first.

Helmith is in development. The desk is not yet funded. A token has not been launched. Prices, funding and any future blotter rows are read from Lighter’s public API on Robinhood Chain.
